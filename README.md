# hjson-formatter

Форматирование файлов `.hjson` в Visual Studio Code.

![Пример](example.gif)

## Что такое Hjson?

[Hjson](https://hjson.github.io/) — это удобный для чтения формат JSON, допускающий более свободный синтаксис.

После установки расширения файлы `.hjson` можно форматировать стандартной командой VS Code **Форматировать документ** (`Shift+Alt+F`).

## Настройка

Расширение поддерживает настройку параметров форматирования. Доступные параметры соответствуют API пакета [hjson](https://www.npmjs.com/package/hjson).

## Форматировщик по умолчанию

Если у вас установлено несколько расширений, поддерживающих форматирование Hjson, можно явно назначить `hjson-vsc` форматировщиком по умолчанию.

Откройте настройки VS Code в формате JSON и добавьте:

```json
{
  "[hjson]": {
    "editor.defaultFormatter": "Sam-Strand.hjson-vsc"
  }
}
```

Расширение использует пакет [hjson](https://www.npmjs.com/package/hjson).
